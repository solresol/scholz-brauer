## Closed obligations

The existing interval enumeration discards any box complement with more than
seven odd-length arithmetic runs at either step u or d1. The previous Lean
halving theorem did not justify this test on the complement before deleting
the exceptions. `Clift109OddRuns.lean` now proves that mathematical pruning
condition, including its application to the original natural edge labelling.

Runs are defined as equivalence classes generated by edges x to x+d whose
two endpoints occur in the input. For positive d these are the maximal runs
in each residue class, including singleton runs. Only classes meeting the
input are counted. The count uses weight multiplicity, hence is ordinary run
length on duplicate-free input. This is a mathematical specification using
quotients and classical equality, not a new executable search representation.

For any finite integer multisets A and E, let S = A + (A translated by d) + E.
Both endpoints of each translated pair belong to the same run. More generally,
for any label constant across these pairs, the number of occurrences of each
label in S is twice its count in A plus its count in E. An odd component
therefore contains an exception. The odd components form a subset of the
classes represented in E, so their number is at most |E|. The proof permits
negative weights and repetitions and needs no bound on their magnitudes.
Without exceptions all components are even.

A separate finite counting argument proves that the number of odd components
has the same parity as the total number of weights. Applying the two proved
19+19+7 remainder factorizations gives, at both steps u and d1:

    oddRunCount(remainder) <= 7
    oddRunCount(remainder) = 1 (mod 2).

Thus each count is 1, 3, 5 or 7. `interval_odd_runs` identifies this remainder
with [0,108] minus the box BEFORE removing either exceptional set and proves
it duplicate-free. `odd_runs_of_budget` supplies both constraints for every
natural labelling of the selected graph with seed 1, terminal M109 and total
cap budget at most 108. It also supplies positive steps u,d1 using the prior
budget/halving theorem. Nine public theorems are added to the dependency audit.
