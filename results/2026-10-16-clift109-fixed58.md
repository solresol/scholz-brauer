## Complete domains and cost search

`Clift109.fixed58_tail_rigid` proves that every candidate has
B51=M51*2^k, B7=M7*2^l, with 0<=k<8, 0<=l<44, and k=0 or l=0.
Enumerate (0,0..43) and (1..7,0), retaining arbitrary bases at
2,4,5,8,15,23,28. No four-fixed-tail or 323-pair reduction is reused.

The existing complement/production enumerator checks every fully determined
original graph equation. Positive terms bound every unknown by a known
descendant, so every branching domain is finite without imposing an arbitrary
shift cutoff. Carry-free sums and seed 1 imply popcount(Bv)=v by induction;
filtering this necessary condition cannot remove a solution.

The concrete performance blocker was producing B8 before using its repeated
consumption, and similarly for B23. Substituting the original equations gives

    B51 = B23*(2^(a28+a51)+2^b51) + B5*2^(b28+a51),
    B23 = B8 *(2^(a15+a23)+2^b23) + B7*2^(b15+a23).

For an equation u*2^A+u*2^B+known*2^C=target, disjointness forces A!=B.
Subtract the known term and divide by 1+2^abs(A-B), then divide by every
power of two that divides the quotient. C and abs(A-B) are strictly less
than the bit length of the positive target/remainder. This enumerates every
possible u. Relaxing the shared shift constraints or disjointness with the
known term only adds candidates; all original equations are checked later.
The helper is an additional domain constraint passed into the existing
recursive enumerator, not a new solver or certificate format.

For each complete base assignment, the existing exact local-shift enumerator
supplies every option, modulo swapping equal-parent parallel edges. The cost
search branches over these options. At each node it takes, for each source
vertex, the maximum of the chosen outgoing shifts and every remaining edge's
minimum available shift. Their sum is a lower bound: prune only when it
exceeds 108. If no branch succeeds, that base assignment is excluded. An
allocation with cost 109 is independently replayed using the existing
summand-index checker, establishing attainability.

## Related local reduction with fixed B51

A separate exact calculation narrows the next problem without a new solver:
fix B51=M51 and enumerate the 109 terminal forms from the existing Lean iff.
For each, use `consumption_domain(B58, M51)`, retain `2*B7<M51` and
`popcount(B7)=7`, and check the original B58 production equation. The inequality
follows from the two occurrences of B7 in B51's positive-summand expansion;
it does not need B58=M58. The population count follows from carry-free sums.

Exactly 54 terminal forms survive locally:

- Every shifted block B58=M58*2^t, 0<=t<=51, permits exactly
  B7=M7*2^l, 0<=l<=43.
- The separated form with parameter b=7 permits only B7=M7.
- The separated form with parameter b=51 permits exactly
  B7=M7*2^l, 0<=l<=43.
- The other 55 separated forms permit no B7 satisfying these conditions.

All 2,333 surviving pairs had their complete local shift sets checked by the
independent nested-shift enumerator. Runtime **1.674960s**, Python 3.9.6,
no random seed; all cases and input hashes are in
`results/2026-10-16-clift109-fixed51-local.json`. The generating calculation
runs `python3` in the repository root, imports the existing script functions,
and applies this complete domain construction:

```python
shapes = [((2**58-1) << t) for t in range(52)] + [
    ((2**(58-b)-1) << (51+b)) + (2**b-1) for b in range(1,58)]
for B58 in shapes:
    candidates = [u for u in consumption_domain(B58, 2**51-1)
                  if 2*u < 2**51-1 and bin(u).count('1') == 7
                  and pairs_cached(2**51-1, u, B58)]
    for u in candidates:
        require(pairs_cached(2**51-1, u, B58) ==
                brute_pairs(2**51-1, u, B58), 'local shift mismatch')
```

This is a complete **local computational domain**, not whole-graph feasibility,
a cost minimum or a new Lean theorem. Earlier production/reuse constraints and
the doubling budget still need to be imposed.
